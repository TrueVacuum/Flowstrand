## [0.1.0] - 2026-08-08

### Added

- ScriptableObject graph, polymorphic node, stable port, and edge data model.
- Runtime execution engine with independent Blackboard and per-node Context state.
- Entry, Log, Delay, Branch, Parallel, Join All, and Join Any nodes.
- Dynamic execution ports with stable IDs and safe removal.
- GraphView editor with grid, search creation, persistence, undo/redo, and copy/paste.
- Protected, automatically created Entry node.
- Graph validation UI and execution-time validation protection.
- Selectable Runner debugging and runtime node-state highlighting.
- Live ScriptableObject AI Context bridge with automatic project instructions.
- Basic Flow sample.
- EditMode tests for graph data, serialization, validation, execution, parallel joins, failure
  handling, custom nodes, and AI Context.
