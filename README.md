# Flowstrand Framework

An extensible visual execution-flow framework for Unity.

Flowstrand separates reusable node implementation from graph authoring: developers create
strongly defined flow nodes, while designers compose and configure those nodes in a visual graph.

## Initial scope

- Control-flow ports only.
- ScriptableObject graph assets.
- Extensible runtime node API.
- GraphView-based editor tooling.
- Blackboard variables.
- Validation and Play mode execution tracing.
- AI-readable graph summaries.
